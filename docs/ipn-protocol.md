# IPN Hand pilot protocol • locked before fitting

I selected the original 320 × 240 frame release, original inclusive frame numbers, and the 56 source IDs in [the split](../artifacts/ipn/split.json). Target indices 1–4 correspond to the original IDs 8/G05, 9/G06, 13/G10 and 14/G11. The fifth class (index 0) combines all other intervals. Every selected source includes exactly one of each target. Selection used split membership, visual background and frame completeness. I chose the 56-recording design to test all four classes and accepted the sparse natural short-pair coverage.

I examined frames 1 and 1801 of all takes for setting compatibility. The published split holds out 13 of the 50 people. The first two underscore-delimited filename fields form 50 four-recording groups consistent with the official grouping. I use 16/4/8 such groups for train/validation/test, two whole recordings each. Distinctive repeated camera setups (such as the vertical blinds, workstation cabinets and ceiling pipes) informed selection. Some white-panel backgrounds are ambiguous. Group names in the manifest describe visible setups. Physical room identity remains unverified. The selected streams are contiguous on the annotation timeline. Numbered JPEGs determine order. Audit exact compressed frame hashes for all selected frames and nearest low-resolution temporal signatures across splits before fitting. Inspect suspicious matches. [Authors' split and collection](https://gibranbenitez.github.io/2021_ICPR_IpnHand.pdf)

I sample every fourth released frame, starting at frame 1. Neural heads share the frozen DINOv2-S/14 cache (four pooled spatial cells, 1,536 values), training-only standardization and square-root inverse-frequency class weights. I compare independent per-tick predictions, means over a centered 15-tick neighborhood, and three residual temporal convolutions (dilations 1, 2, 4). A multinomial logistic model uses grid-pooled Farnebäck flow with border compensation and an expansion feature. It uses the same streams and ticks. The app will use the temporal checkpoint for seed 17, independent of test ranking.

I fix three neural seeds (17, 31, 73), two AdamW rates (0.0005 and 0.0015), at most 30 epochs, patience seven, 90-tick contiguous chunks with seven ticks of context on each side and batch size 16. Select epoch on validation segment F1@0.5 using score 0.65 and two consecutive ticks, breaking ties by validation loss. On that checkpoint choose the validation decoder from 0.65/0.80/0.90 and minimum 2/3 ticks. Choose learning rate by average validation F1 across seeds. The flow model compares two L2 penalties on validation. Seed 17 is primary. Other seeds measure fit variation.

I score known-boundary classification by mean log probabilities over true movement intervals (four candidate labels). Full-stream F1 at tIoU 0.1/0.25/0.5 uses descending-IoU one-to-one matches. I report unmatched predictions per nominal minute, matched endpoint MAE, exact chronological lists, unordered lists and pair recall. A 12-second nonoverlapping blind-tile analysis includes clipped targets visible inside each tile and drops the last partial tile. Original frame units are authoritative. Nominal time uses 30 released frames per second.

Sensitivity interventions isolate actual annotated bouts, replicate-pad their own edges, and score correct/reversed/seeded shuffled observations against the original labels. Recompute optical flow after each intervention. The pooled oracle control uses one mean of the entire bout. For AB/BA, use each unordered pair of the four real bouts twice, exchanging positions with context reset at the join. Score which assignment of the two known labels maximizes their summed logit and also report both top-1 labels correct without the pair hint. This diagnostic supplies boundaries. Whole-stream evaluation supplies neither boundaries nor names. Bootstrap entire test participant groups 2,000 times, pairing model draws. The feasibility targets are +0.05 macro F1 and +0.05 segment F1@0.5 over the appearance controls with paired intervals excluding zero, plus a 0.10 shuffle accuracy drop.

I used Codex for implementation, analysis and documentation. The work is local. Only the split, numeric results, figures and trained heads belong in the repository.
