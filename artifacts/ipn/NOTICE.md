# IPN Hand pilot attribution

I release the pilot-specific trained heads, split manifest, aggregated results and derived figures in this directory under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Credit TemporalLens contributors for the heads and analysis. Credit Gibran Benitez-Garcia, Jesus Olivares-Mercado, Gabriel Sanchez-Perez and Keiji Yanai for **IPN Hand: A Video Dataset and Benchmark for Real-Time Continuous Hand Gesture Recognition**, ICPR 2020. The authors distribute the original data and annotations under CC BY 4.0. I selected a subset, subsampled the released frame timeline, grouped labels, computed embeddings and trained classifiers. The directory contains numeric results and model state dictionaries. [Dataset and citation](https://gibranbenitez.github.io/IPN_Hand/)

The frozen DINOv2-S/14 image encoder comes from Meta's DINOv2 project and is used under Apache-2.0. Its weights are obtained separately by the local setup command. Transformers (Apache-2.0) provides its model implementation. OpenCV supplies Farnebäck flow. The original repository MIT license applies to the TemporalLens source code.
